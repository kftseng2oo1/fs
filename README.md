# 風水羅盤・吉宅鑑定

輸入出生年月日與房屋坐向，依生肖、命卦與五行生剋分析住宅吉凶，並給出樓層與房間配置建議。

**線上使用**：https://kftseng2oo1.github.io/fs/

## 主要功能
- 依出生日期判斷生肖（以立春為界）與命卦（東四命／西四命）
- 坐向可手動選擇，或用「📡 手機指南針量測」實際測量大門方向
- 分析坐向與命卦的五行關係（比和、生入、洩出、克入、被克）並評分
- 建議：適合樓層、文昌位、財位、臥室顏色、各房間配置

## 使用方式
1. 選擇出生年月日（自動換算生肖）
2. 選擇或量測房屋坐向，按「✓ 確認此坐向」
3. 按「☯ 開始鑑定」查看結果

## 技術與依賴
- 單檔 HTML PWA（`index.html` 內含全部 HTML/CSS/JS），`manifest.json` + `sw.js` 提供安裝到主畫面與離線快取。
- `DeviceOrientation`（量測坐向），純前端計算，不需網路
